# 萤火虫星空漫游（2D）

在星空中漫游，收集萤火虫般的金色粒子，躲开陨石，一共 50 关。

## 在线玩

https://yang1-create.github.io/firefly_progress/

打开链接直接玩，不需要安装任何东西；把 index.html 下载到本地，断网时双击也能玩。

## 操作

- 手机：按住屏幕任意位置拖动，摇杆会出现在手指下方，抬手即停
- 电脑：WASD 或方向键移动，R 重开本关

## 玩法

- 靠近金色光点就能收集，收满本关要求的数量后自动进入下一关
- 碰到陨石立即失败，本关重来
- 每关有时间限制，剩余时间显示在顶部
- 右上角雷达显示你与光点、陨石的相对位置
- 越往后光点越多、陨石越多，粒子开始轻微漂移，难度递增

## 存档

进度保存在浏览器本地，输入同一个名字会从上次的关卡继续。
换浏览器、清缓存、换设备会从第 1 关重新开始，不同设备之间不互通。

## 实现

单个 index.html 文件，用 Canvas 2D 绘制，没有任何外部依赖和网络请求，因此可以离线运行。
